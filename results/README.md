# Generated results

Write run outputs under a case-specific directory, for example
`infinite_medium_square/`, `infinite_medium_quads/`, `texas_eigenvalue/`, or
`texas_fixed_source/`. These directories are ignored by Git by default.

Preserve the input configuration, mesh resolution, quadrature order, software versions,
convergence history, and command used with each run. Separate fields, tables, and figures
within a run only as needed. Curated figures for the report may be committed under `docs/`
with a reproducible generation command.
