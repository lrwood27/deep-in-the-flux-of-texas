# Mesh files

- `reference/tx_mesh.msh`: the existing committed Texas mesh, preserved as a reference artifact.
  It is not a verified solver benchmark or a convex-hull/void mesh.
- `generated/tx_mesh.msh`: regenerated by the preprocessing script and ignored by Git.

The current generator meshes only the simplified Texas mainland. Convex-hull construction
and the surrounding void mesh remain future work. Regenerating a mesh does not overwrite
the committed reference artifact.

Keep small square-grid verification meshes with their cases under `verification/` if needed.
