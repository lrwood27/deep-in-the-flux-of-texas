# Automated tests

No automated tests are implemented yet. Place focused tests of implemented routines here:
cell areas/normals and neighbors, quadrature normalization, source/material assignment,
boundary inflow, step cell balance, and iteration stopping criteria.

Use tiny deterministic inputs. End-to-end analytical cases and refinement studies
belong in `verification/`; tests may run small versions once a test runner is selected.
Do not require elevation downloads or the full Texas calculation for routine unit tests.
