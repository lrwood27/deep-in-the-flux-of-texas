# Case inputs

Put small, version-controlled simulation inputs here once an input format is chosen.
Do not embed team-specific paths or generated flux arrays in case inputs.

Future cases should declare mesh/geometry, material assignments, 2 MeV cross sections
(or microscopic data plus densities/compositions), length units, angular quadrature,
external source strengths, boundary conditions, iteration tolerances, and output location.
Keep the eigenvalue and source-driven Texas cases distinct.
Record the source of cross-section data and conversion assumptions.

Cross-section datasets, densities/compositions, source strengths, quadrature order,
and solver tolerances have not yet been chosen; no default numerical values are implied here.
