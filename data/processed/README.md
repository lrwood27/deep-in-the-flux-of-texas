# Generated solver inputs

Preprocessing writes `mesh_params.npz` here; generated NPZ files are ignored by Git.
The current export contains `nodes`, `quads`, `centers`, `cell_mat`, and `cell_source`.
See the root README for shapes and coordinate units.

Hull/void cells, explicit region IDs, face connectivity, cross sections, and numerical
source strengths are still pending. The current export alone is not a complete solver input.
