# Project documentation

Keep numerical derivations, design decisions, data-source attribution, and report or
presentation source files here. The root README is the project entry point and scope record.

Important decisions to document as implementation proceeds include unit scaling,
2 MeV cross-section provenance, material densities/compositions, source strengths,
angular quadrature, sweep-cycle handling, and convergence criteria.
Reference generated study outputs in `results/` with the commands that produced them.
